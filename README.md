# JR Media

Première version du projet JR Media, une interface web mobile-first destinée à devenir une application Android.

## V1

- Accueil
- Catalogue Films
- Catalogue Séries
- Dessins animés
- Recherche locale
- Favoris avec stockage local
- Fiche détaillée
- Boutons Regarder / Télécharger prêts pour les prochaines intégrations
- Design responsive mobile et desktop

## Prochaines étapes

1. Ajouter une base Supabase pour le catalogue et les comptes.
2. Ajouter une source de contenus légalement distribuables.
3. Ajouter le lecteur vidéo.
4. Ajouter les téléchargements autorisés.
5. Ajouter les fonctions IA via Google AI Studio / Gemini.
6. Préparer la PWA puis l'application Android et l'APK.

> Les contenus protégés ne doivent être distribués ou téléchargés que lorsque les droits ou autorisations nécessaires existent.
